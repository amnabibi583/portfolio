# Amna Bibi — Personal Portfolio

A one-page portfolio built with plain HTML and CSS.

## Deploy with Netlify Drop

1. Open [Netlify Drop](https://app.netlify.com/drop) and sign in or create a Netlify account.
2. Keep `index.html`, `cv.pdf`, and this README in the same project folder. Include `DNS_Walkthrough.md` if you want it available in the deployed files.
3. Drag the entire project folder onto the Netlify Drop upload area.
4. Wait for the upload to finish. Netlify will provide a live `netlify.app` URL.
5. Open that URL and test the navigation, contact links, and Download CV button.

No build command or publish directory is needed because this is a static HTML website.

## Deploy and test the contact form on Netlify

1. Deploy the project with Netlify Drop using the steps above, or connect the GitHub repository in Netlify.
2. In the Netlify site dashboard, open **Forms** and confirm that the `contact` form is detected after the first deploy.
3. Open the live site, scroll to **Contact**, and submit a test message with a name, email, and message.
4. Return to **Forms → contact** in Netlify and confirm the submission appears there.
5. Netlify handles the form submission; no database, API key, or server code is required.
